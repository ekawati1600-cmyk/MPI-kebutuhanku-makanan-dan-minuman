MPI ONLINE — KEBUTUHANKU: MAKANAN DAN MINUMAN
TK Kuncup Pertiwi Mikuasi

ISI PAKET
- index.html: aplikasi MPI siap dipublikasikan sebagai situs web statis.

CARA PALING MUDAH MEMBUATNYA ONLINE (NETLIFY DROP)
1. Ekstrak ZIP ini terlebih dahulu.
2. Buka https://app.netlify.com/drop
3. Seret folder "MPI_Online_Kebutuhanku" (atau folder berisi index.html) ke area unggah.
4. Tunggu proses selesai. Netlify akan memberikan alamat situs (URL) yang bisa dibuka dan dibagikan.
5. Buka URL tersebut untuk menguji aplikasi di HP atau komputer.

CATATAN
- File ini merupakan situs statis; tidak memerlukan database atau server khusus.
- Setelah online, aplikasi dapat dibuka melalui tautan selama situs hosting tetap aktif.
- Fitur suara menggunakan dukungan suara pada browser/perangkat, sehingga hasilnya dapat berbeda-beda.
- Skor kuis tidak disimpan secara permanen.
- Jangan membagikan informasi pribadi anak melalui aplikasi ini.

ALTERNATIF
Anda juga dapat mengunggah file index.html ke layanan hosting statis seperti GitHub Pages.
